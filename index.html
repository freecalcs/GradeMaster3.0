Category weights

Each class has its own categories. For example, one class can use Tests 50%, Homework 30%, Projects 20%, while another uses different percentages. Weights are normalized to the total you enter.

Class grade = sum(category grade × category weight) ÷ sum(category weights)

Formula

Current grade counts for the percentage left after the final weight.

Final Grade = (Current Grade × (1 − w)) + (Final Score × w)

Use w as a decimal: 15% = 0.15. The final exam replaces that portion of your course grade; it is not extra credit.

Needed exam score = [Target − Current × (1 − w)] ÷ w

How GPA weighting works

Enter a number grade from 0–100. Each course is weighted according to its type.

90–100 = 4.0 (A)
80–89 = 3.0 (B)
70–79 = 2.0 (C)
60–69 = 1.0 (D)
Below 60 = 0.0 (F)

Regular courses use a 4.0 maximum. Use the AP / Honors weighting selector to set the maximum for each advanced course type.

You can set both AP and Honors to 5.0, or choose which one uses 4.5.
